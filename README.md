# 大肥鱼的天屋 · dafeiyu-room

一个蓝色半立体小屋的 Windows 桌面程序（Electron）。大肥鱼住在里面：会散步、看书、吃白米饭、睡觉，光照会跟着清晨、白天、黄昏、夜晚变化，还能开关灯。接上 AI 以后，她能和你聊天，还会自己经营户外的「小天地」。

AI 和小天地的逻辑都在独立的 DSH 插件仓库 **[dsh-room-world](https://github.com/amimi-wenke/dsh-room-world)** 里；本仓库只负责画面和本机连接。

## 能做什么

| 功能 | 需要什么 |
|---|---|
| 小屋里的日常活动、光照、开关灯、点家具互动 | 只要这个 exe |
| 和她聊天 | DSH，加上 dsh-room-world 插件 |
| 小天地（农场、花园、池塘、商店、图鉴） | DSH，加上 dsh-room-world 插件 |
| QQ 里和她聊小屋、引导她经营小天地 | 再接一个运行在 DSH 里的 QQ 机器人 |

## 快速开始

### 只看小屋（不用装别的）

1. 到 [Releases](https://github.com/amimi-wenke/dafeiyu-room/releases) 下载最新的 `Dafeiyu-Room-<版本>-portable.exe`，放到任意文件夹，比如 `D:\大肥鱼的小屋\`。
2. 双击运行。**第一次启动要等 5～10 秒**：这是便携版，要先解压，这段时间里什么都不显示，这是正常的，不要连点。
3. 如果弹出「Windows 已保护你的电脑」：exe 没有数字签名才会这样。点「更多信息」→「仍要运行」。

这样就能看到小屋了。右上角的按钮：

- **◷ 跟随时间**：光照跟着现实时间变化。点一下可以手动预览清晨、白天、黄昏、夜晚。
- **自由活动 · 开 / 关**：开着时她会在房间里自己找事做。
- **灯**：点房间里的灯可以开关。
- 点书架、电脑、床、电饭锅等家具，她会走过去互动。

### 接上 AI 聊天和小天地

1. 安装并打开 DSH（DeepSeek Harness），在设置里选好**默认模型**。
2. 安装 **dsh-room-world** 插件，步骤见 [插件仓库的 README](https://github.com/amimi-wenke/dsh-room-world#安装)。装好后重启 DSH。
3. 打开小屋，点右上角的 **连接 DSH**。按钮变成「和她聊聊 · 已连接」，就表示连上了。
   - 小屋会自动读取插件写在 `%USERPROFILE%\.dsh\room-world\host.json` 里的地址，一般不用填任何东西。
   - 必须先启动 DSH 再点连接。DSH 重启以后，回到小屋点一下「连接 DSH · 重试」。

### 和她聊天

点 **和她聊聊** 打开聊天面板，在输入框里打字。Enter 发送，Shift+Enter 换行。

- 她知道自己此刻在房间里做什么，也知道小天地的进度。
- 你可以直接说「去看书吧」「去吃饭」，她会自己决定要不要去。
- 桌面上的聊天只保存在本机插件里，**不会发到 QQ**。

### 小天地

点 **小天地** 打开面板：

- **概况**：她当前的打算和步骤，每块地的生长阶段，池塘状态，今日委托和行情。
- **仓库**：种子、物品、收获的果实和花、钓到的鱼、鱼缸、花瓶。
- **商店**：她能买的东西和价格。
- **图鉴**：收集进度，以及每个物种的最大纪录。
- **日记**：里程碑和最近做过的事。

**小天地里的事都由她自己做**：播种、浇水、收获、收竿、买卖、煮饭、养鱼，你不能替她点。你能做的是引导：

- 在面板底部**留个心愿**，比如「想看看巨大的西瓜」「鱼缸里想多几条鱼」。她下次规划时会考虑，要不要做、怎么做由她决定。
- 点 **请她重新想想打算**，让她马上重新规划。这会占用当天的规划次数，默认每天 4 次。
- 接了 QQ 机器人的话，在 QQ 私聊里跟她说到小天地的话（种地、钓鱼、买卖、某种作物……），也会自动记成心愿。

小天地按现实时间慢慢推进：作物要 1.5～10 小时，每个生长阶段都要浇一次水；鱼咬钩后 10 分钟内要收竿。适合长期挂着。

## 常见问题

**双击 exe 没反应**

- 先等 10 秒，第一次启动要解压。
- 已经开着一个的话，再双击只会把已有的窗口切到前面。看看任务栏。
- 被 SmartScreen 拦了：点「更多信息」→「仍要运行」。
- 如果是从受限的开发目录里运行，可能会闪退。复制到普通文件夹再运行。

**小天地显示「DSH 里加载的还是旧版 dsh-room-world 插件」**

更新插件后要重启 DSH，或者在 DSH 插件页重载 dsh-room-world，再点「连接 DSH · 重试」。

**连不上 DSH / 聊天没回复**

- 确认 DSH 已经启动，插件页里 dsh-room-world 是启用状态。
- 确认 DSH 设置里选了默认模型。
- 确认 `%USERPROFILE%\.dsh\room-world\host.json` 文件存在。它是插件启动后生成的，不存在说明插件没加载。

**她在小天地里很久没动**

- 看看状态栏：她可能在歇息，面板上会显示几点后继续。
- 小天地由插件推进，DSH 关着时不会走动；DSH 重新打开后，按现实时间补算生长进度。

## 开发与构建

需要 Node.js 22 及以上和 npm。第一次安装或构建时，会从 npm 和 Electron 官方发布源下载依赖。

```bash
npm ci
npm test
npm start
npm run build:win
```

构建产物在 `release/Dafeiyu-Room-<版本>-portable.exe`，约 140 MB，发布到 GitHub Release，不要提交进仓库。推送 `v*` 格式的 tag 时，GitHub Actions 会自动构建 Windows 版本。

浏览器调试：运行 `node connector/server.mjs`，然后打开 `http://127.0.0.1:37621/`。

### 项目结构

- `desktop/main.mjs`：Electron 窗口，以及本机连接器的生命周期。
- `connector/server.mjs`：本机连接器。读取 `~/.dsh/room-world/host.json` 找到插件接口；浏览器只拿到短期会话；负责凭据隔离和重试去重。
- `room.js` / `room.css` / `index.html`：房间、角色动作、路径和时段光照。`index.html` 内嵌了 PNG（由 `bundle-assets.mjs` 生成），运行时不需要外部图片。
- `dsh-client.js` / `dsh.css`：聊天面板、房间状态回报、指令确认，以及小天地面板。
- `assets/`：房间和角色的原始图片；`assets/world/` 是小天地素材。
- `docs/xiaotiandi-art-assets.md`：小天地美术需求清单，欢迎贡献素材。

### 与插件的接口

桌面程序只通过 HTTP 和插件通信，不导入插件代码：

- 连接器从 `host.json` 读取插件的本机地址和 token，只接受回环地址；
- 房间每次心跳上报当前动作，拉取房间指令，拉取聊天和小天地状态；
- 小天地面板只调用查看、商店、图鉴、留心愿、请她重新规划这几个接口。

接口细节见 [dsh-room-world 的 README](https://github.com/amimi-wenke/dsh-room-world)。
