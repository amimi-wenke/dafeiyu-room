# 小天地美术素材

本目录为蓝色半立体小屋配套 PNG。图像使用内置 `image_gen` 逐项生成；原始输出保存在 作者本地目录。原图不会被规格化脚本覆盖。用户允许的本地处理仅包括等比缩放、透明留边、锚点对齐和检查预览。

## 文件和清单

- `world-manifest.json`：可移植的相对文件名、尺寸、锚点和 SHA-256；程序优先读取此文件。
- `layout.json`：房间摆件、鱼缸游动范围、户外田地及互动位置。坐标均相对于完整场景图片，左上为 `(0,0)`，右下为 `(1,1)`。
- `generation-prompts.json`：逐项生成提示词与后续修图提示词。
- `manifest.json` 和每张图旁的同名 JSON：本机完整导出记录，包含原图路径与 D 盘副本路径。
- `review/`：检查时保留的早期版本，不是程序默认使用的素材。

## 规格和复用

图标 256×256；地块、植物与室内物件 384×384；游动小鱼 96×96；角色 1240×1269；户外背景 1672×941。物件与角色为 RGBA 透明图，场景为不透明图。PNG 原生 alpha 必须保留；完全透明像素中的隐藏 RGB 不代表实际可见的光圈。

种子袋按需求允许的方案共用 `seed-blank.png`，在标签上叠加对应物种的图标。幼芽共用 `crop-stage-1.png` 与 `flower-stage-1.png`，完整别名映射在可移植清单的 `aliases`。每个物种的成长和成熟阶段分别提供独立图片。

## 接入约定

场景按原图比例完整显示。所有互动点先转为场景图片局部坐标，再映射到显示矩形；不要把含黑边或留白的窗口尺寸当成场景尺寸。这样窗口缩放后不会把角色目标点算到房间外面。

角色使用 `layout.json` 的动作锚点；不要把头顶或图片中心当脚底。站立、蹲下和坐着动作有不同的身体高度，渲染时保持同一世界缩放比例。田地中心与地块精灵的底边锚点分别记录，种植物时使用种植点。

四时段背景使用同一场景布局。切换时将相邻时段放在上下两层，令顶层 opacity 在几秒内平滑变化；角色与新增摆件采用同一环境色调，避免背景变夜晚但物件仍像正午。室内物件不单独生成各时段偏色版，按需求允许的方案由程序统一叠加环境滤镜。

素材包中的 `world-art-offline.js` 把所有最终 PNG 以内嵌 data URL 导出到 `window.BIG_FISH_WORLD_ART`；仅在程序接入时显式加载。提供素材与离线包不代表现有可执行程序已自动启用户外玩法。
