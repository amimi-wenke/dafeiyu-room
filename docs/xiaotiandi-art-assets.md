# 小天地美术素材清单

配合 dsh-room-world 插件仓库里的《小天地循环与自主规划方案》（docs/2026-11-05-xiaotiandi-loop-plan.md）。没有素材时程序也能用：面板先用文字和 emoji 占位。素材按批次接入，到一批换一批。


> **2026-11-05 晚修订**：户外只保留田园和池塘两个场景；田园里**不要画小摊**，中间放休息用的长椅；商店改为「出门去镇上集市」，用 `away-postcard-market.png` 表现；角色动作去掉 `sell`。生成计划已同步修改，请不要恢复田园小摊。

## 通用规格

- 风格：沿用现有的蓝色半立体小屋（`assets/room.png`）和大肥鱼角色图（`assets/idle.png` 等），色调偏蓝、柔和。
- 格式：PNG。物件和角色用透明背景；场景用不透明背景。
- 尺寸：
  - 角色动作图：和现有的一致，约 1240×1270，脚底锚点和 `idle.png` 对齐；
  - 场景：和 `room.png` 一致，1672×941；
  - 图标：256×256，内容居中，四周留 16px 空白；
  - 地块和植物：384×384，底部中心是地面锚点。
- 命名：小写英文加连字符，物种名和插件代码里的 id 一致（dsh-room-world 的 `lib/species.js`），例如 `crop-watermelon-ripe.png`、`fish-koi.png`。
- 存放：放到 `assets/world/`，打包时内嵌，和现有资源一样离线可用。高分辨率原图由作者本地保存，不随仓库分发。
- 权利：沿用 ASSETS.md 的约定。人设相关的图在公开前需要确认授权。

## 第 5 批：户外场景

**只做两个户外场景：田园和池塘。** 原计划里单独的农场、花园、商店和小路场景都取消了。**商店功能保留，但改成「出门去镇上集市」**：她买种子、卖收成、交委托时会自己出门一小会儿，所以不需要商店场景，用一张集市明信片来表现。

| 文件 | 说明 |
|---|---|
| `outdoor-field-<phase>.png` ×4 | **田园**。左半边是农田，8 块，四列两排；右半边是花圃，8 个，四列两排；中间靠后是一块休息的草地，放一张长椅（不放小摊）。左上远处能看到小屋的门，右边有小路通往池塘。场景里画满 8+8 块空地：还没扩建的地块由程序显示成「未开垦」 |
| `outdoor-pond-<phase>.png` ×4 | **池塘**。左前方是钓鱼位，有小码头和小凳的位置；中间留出放浮漂的水面；左边有小路回田园 |

`<phase>` 是 `morning`、`day`、`dusk`、`night`。先出白天版，其他时段在白天版的基础上只改光照，构图、地块、物件位置必须完全不变。

## 交付顺序建议

1. 第 1～3 批已完成：图标、地块和生长阶段、小屋摆件。
2. **田园和池塘的白天版场景**，加上两个场景的锚点坐标（见下）。有了这两张，门口菜单就能看到她在户外干活。
3. 田园和池塘的动作图：`plant`、`water-can`、`harvest`、`fish-wait`、`fish-show` 这 5 张最常出现，优先做。
4. 其余时段的场景、剩下的动作图、出门和回家。
5. 集市明信片（她每次买卖都会用到），然后是菜单图标和其他明信片。

## 交付后需要提供给程序的信息

写在 `assets/world/layout.json` 里，坐标是相对整张场景图的比例，左上角为 (0,0)，右下角为 (1,1)：

- **小屋**：鱼缸可游动区域、花瓶位置、贝壳罐位置、门的位置；
- **田园**：8 块农田、8 个花圃的中心点（种植点），以及她站着照料每块地时的脚底位置；回小屋和去池塘的出入口；
- **池塘**：钓鱼时的脚底位置（站和坐分开记录）、浮漂位置、回田园的出入口；
- **角色动作图**：脚底锚点如果和 `idle.png` 不一致，需要单独说明。
